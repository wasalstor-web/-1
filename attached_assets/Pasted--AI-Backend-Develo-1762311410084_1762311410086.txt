## 🚀 4. Animations & Interactions

### 4.1 Page Transitions
```
عند التنقل بين الصفحات:

Fade Out (الصفحة الحالية):
- Opacity: 1 → 0
- Duration: 0.2s
- Ease: ease-out

Fade In (الصفحة الجديدة):
- Opacity: 0 → 1
- Transform: translateY(20px) → translateY(0)
- Duration: 0.3s
- Ease: ease-out
- Delay: 0.1s
```

### 4.2 Scroll Animations
```
العناصر تظهر عند Scroll:

Fade + Slide Up:
- Initial: opacity 0, translateY(40px)
- Animate: opacity 1, translateY(0)
- Duration: 0.6s
- Ease: cubic-bezier(0.4, 0, 0.2, 1)
- Stagger: 0.1s بين العناصر
- Trigger: عند 20% من العنصر مرئي
```

### 4.3 Hover Interactions
