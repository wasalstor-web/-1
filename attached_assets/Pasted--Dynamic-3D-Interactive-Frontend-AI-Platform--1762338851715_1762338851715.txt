تمام ✅
اللي تصفه هو واجهة Dynamic 3D Interactive Frontend لمنصة “مبسط AI Platform”، تجمع بين التجربة البصرية الفاخرة والتحكم التفاعلي في المظهر واللغة.
خلّيني أشرح لك كيف نعيد تصميمها بأسلوب شركات التقنية الكبرى (مثل Apple + Zebra Technologies) لكن بروح “مبسط” 👇

⸻

🎯 الهدف

واجهة واحدة، 3D متحركة ثنائية اللغة (AR/EN)، تتغير ديناميكياً حسب تفاعل المستخدم، وتُظهر هوية “مبسط AI Platform” بوضوح.

⸻

🧠 الهيكل الذكي المقترح

1. Hero Section (الواجهة الرئيسية)
	•	شعار ثلاثي الأبعاد متحرك:
	•	يظهر “مبسط AI” بالعربية و”Mobsaṭ AI Platform” بالإنجليزية مع حركة دوران ناعمة (Rotation + Light Sweep).
	•	يستخدم WebGL / Three.js لخلق عمق بصري واقعي.
	•	تأثيرات Parallax أثناء تمرير الصفحة (Scroll Motion).

2. زر التحويل الديناميكي (Mode Switcher)
	•	زر في الزاوية العليا 👇
	•	يبدل بين الوضع الداكن والفاتح (Dark / Light) بتأثير Fade + Morph.
	•	يبدل الخط والظل تبعًا للنمط المختار.
	•	ينفذ عبر Framer Motion + Tailwind Variants.

3. النظام اللغوي المتزامن (Dual Language Engine)
	•	العرض ثنائي اللغة في الوقت نفسه (العربية يمين – الإنجليزية يسار).
	•	الجملة “منصة مبسط للذكاء الاصطناعي / Mobsaṭ AI Platform” تُعرض بدمج مرن داخل نفس الرسمة 3D.
	•	التحويل يتم بالضغط أو بالسحب (Swipe-to-Switch).

4. قسم الاشتراكات (Pricing Section)
	•	بطاقات تفاعلية بأسلوب “Glass Morphism”.
	•	الأسعار بالريال السعودي (SAR) تلقائيًا.
	•	يُضاف تلقائيًا “🇸🇦 المملكة العربية السعودية” بجانب السعر.
	•	تحريك Hover يعرض تفاصيل أكثر مع حركة Pop-Up شفافة.

5. نظام التحكم بالمنطقة والعملة
	•	API مدمج يقرأ الموقع الجغرافي (GeoIP) لتحديد المنطقة تلقائيًا.
	•	إعدادات المستخدم تسمح بتغيير الدولة/العملة يدويًا.

6. انتقالات ثلاثية الأبعاد (3D Navigation Transitions)
	•	عند التنقل بين الصفحات (مثلاً من “الرئيسية” إلى “الخطط”):
يتم تشغيل انتقال ثلاثي الأبعاد كأنك تنتقل بين “Panels” داخل مكعب دوّار.

⸻

🧩 التقنيات المقترحة للتنفيذ

الجزء	التقنية المثلى	الوصف
الحركة الثلاثية	Three.js + React Three Fiber	لتصميم الحركة 3D والانيميشن.
التبديل الديناميكي	Framer Motion + TailwindCSS	لتطبيق تأثيرات الانتقال السلسة.
إدارة اللغات	i18next + React Context	عرض العربية والإنجليزية بشكل متزامن.
واجهات الأسعار	Next.js Dynamic Components	تحميل ديناميكي حسب العملة والمنطقة.
