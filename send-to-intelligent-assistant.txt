انسخ هذا النص والصقه في المساعد الذكي (Intelligent Assistant):

───────────────────────────────────────────────────────────────────

ارفع مشروع Mubsat AI الكامل للسيرفر 46.202.159.100

التفاصيل:
• السيرفر: root@46.202.159.100
• المجلد: /var/www/mubsat-ai
• Node.js: /root/.nvm/versions/node/v24.11.0/bin

الخطوات المطلوبة:
1. جهّز PostgreSQL (database: mubsat_ai, user: mubsat_user)
2. ثبّت PM2 globally
3. أنشئ مجلد /var/www/mubsat-ai
4. ارفع كل ملفات المشروع من Replit
5. أنشئ .env file بـ:
   - NODE_ENV=production
   - PORT=5000
   - DATABASE_URL=postgresql://mubsat_user:<password>@localhost:5432/mubsat_ai
   - SESSION_SECRET=<generated>
6. أنشئ ecosystem.config.js لـ PM2 (2 instances, cluster mode)
7. اضبط Nginx reverse proxy للـ port 5000
8. نفّذ: npm install && npm run build && npm run db:push --force
9. شغّل بـ: pm2 start ecosystem.config.js && pm2 save
10. تحقق من http://46.202.159.100

ولّد كلمات سر آمنة وأعطني تقرير كامل بعد الانتهاء.
